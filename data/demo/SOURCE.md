# FlowDesk 企业协作与运营分析平台 · Q3 用户反馈治理与 Q4 版本规划

## 数据说明

`flowdesk_feedback.csv` 是 EchoDesk 的正式演示数据集，专门用于现场演示「导入 → 清洗 → 语义聚类 → PRD 生成 → 审核 → 导出」完整链路。

- 数据性质：合成数据，仅供产品演示、测试和截图使用，不代表真实用户或真实企业。
- 行数：60 条；主题：登录体验、数据导出、客服支持，各 20 条。
- 隐私：不含真实用户 ID、姓名、联系方式或业务机密。
- 预期结果：通常可得到 3 个主题簇；边界样本是否被识别为噪声取决于向量模型和运行环境。

## 字段

| 字段 | 含义 |
| --- | --- |
| `feedback_text` | 反馈原文；导入页默认选择的文本列 |
| `feedback_id` | 合成反馈编号 |
| `source` | 模拟来源渠道 |
| `role` | 模拟提交者角色 |
| `submitted_at` | 合成提交日期 |
| `severity` | 演示用优先级：P0 / P1 / P2 |

## 推荐演示话术

1. 在导入页上传本文件，确认预览后选择 `feedback_text`。
2. 进入洞察页执行清洗和聚类，展示主题数量、情感和代表原文。
3. 勾选三个主题生成 PRD，强调每项建议都能回溯到反馈原文。
4. 在审核页修改一处内容，再进入导出页下载 Markdown、JSON 和 CSV。

## 解释边界

这份数据用于稳定展示产品能力，不用于证明真实市场规模、用户满意度或模型线上效果。真实效果应使用经过授权的脱敏数据，并结合真人 PM 盲评和问卷实验验证。
