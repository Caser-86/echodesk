## 1. 问题定义

- 用户问题：非结构化反馈 → 结构化需求输入的转化耗时大、难回溯。
- 我们解决：归类 / 去重 / 初步翻译 / 文档草稿化。
- 我们不做：自动采集、团队协作、最终优先级决策。

## 3. 核心用户故事

1. 作为 PM，我想上传一份导出的评论 CSV，以便不用手工粘贴拆分。（M1）
2. 作为 PM，我想让系统自动把海量评论归成若干主题，以便我不用逐条读。（M3）
3. 作为 PM，我想看到每个主题下的原始反馈摘录，以便验证 AI 归类是否可信。（M4 回溯）
4. 作为 PM，我想在 AI 生成的 PRD 草稿上直接编辑并采纳，以便保留最终决策权。（M5/M6）
5. 作为 PM，我想导出成 Markdown 给研发，以便直接进入排期讨论。（M7）
6. 作为 PM，我想把主题拆解成用户故事卡，以便把洞察直接带入评审和排期。（S2）
7. 作为 PM，我想回看历史分析结果，以便比较不同批次反馈的处理过程。（S3）

## 4. 核心流程

导入 → 清洗 → 聚类 → 洞察 → PRD草稿 → 人工审核 → 导出
