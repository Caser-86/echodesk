# 03 · 指标与验证

> 状态：待完成（D11 指标页 / D12 验证）

## 指标体系

| 指标 | 定义 | 目标 | 采集 |
|---|---|---|---|
| 北极星：PRD 采纳率 | (采纳+轻改段)/总段 | ≥60% | 审核日志 |
| 端到端时长 | 导入→导出 | ≤10min/500条 | 时间戳 |
| 效率对比 | 同任务人工基线 | ≥10× | 访谈+自测 |
| 主题命名合理性 | 盲评1~5 | ≥3.5 | 自评+盲评 |
| 拒绝原因分布 | 幻觉占比 | ≤15% | 审核日志 |
| 单次API费用 | 全管线 | ≤¥1 | 用量统计 |

## 验证实验设计

- 被试：本人 + 2~3 位 PM 朋友
- 任务：同一份 500 条演示数据完整走一遍
- 测量：耗时 / 采纳率 / 可用性 1~5 / 盲评混洗
- 产出：本文件"实验结果"章节
